### 1.2. Create VqAmrWb.py
- **Action:** Copy the entire content of `python_scripts/VoiceQuality/wb_voice_quality_analyzer.py` to a new file named `python_scripts/VoiceQuality/VqAmrWb.py`.

## 2. Modify VQEVSanalyzer.py for EVS WB MOS Thresholds

### 2.1. Update MOS Thresholds
- **Action:** In `python_scripts/VoiceQuality/VQEVSanalyzer.py`, locate the `parse_mos_metrics` function.
- **Change:** Modify the line calculating `'% MOS < 3.0'` to calculate `'% MOS < 3.4'`.
  - **Original Line (approx. line 53):** `'% MOS < 3.0': (mos_values < 3.0).sum() / len(mos_values) * 100,`
  - **Modified Line:** `'% MOS < 3.4_alt': (mos_values < 3.4).sum() / len(mos_values) * 100,`
  - **Note:** The script already has a `'% MOS < 3.4'` entry. To avoid duplicate keys, the new entry will be temporarily named `'% MOS < 3.4_alt'`. After confirming the change, the original `'% MOS < 3.0'` will be removed, and the existing `'% MOS < 3.4'` will be retained as the single metric.
- **Reason:** To align the EVS WB VQ analysis with the new requirement of reporting `% MOS < 3.4` for both specified thresholds.

- **Action:** In `python_scripts/DataPerformance/run_all_data_analysis.py`, locate the `elif directory_info["analysis_type"] == "voice_quality_combined":` block (approx. line 295).
